# 隐私与 AI 边界

## 数据处理

- 饮食和运动记录默认保存在本地 SQLite，健康档案保存在本地偏好存储。
- 用户确认前，AI 识别结果仅作为草稿，不自动形成正式记录。
- 服务端模式下 API Key 只保存在服务端；客户端使用 JWT 调用领域接口。
- 演示图片应移除姓名、头像、账号、精确位置和完整运动轨迹。

## AI 使用边界

- AI 不重新计算程序已经计算的总时长、总距离、次数和覆盖率。
- 截图中没有明确出现的数据必须返回空值，不允许根据常识补全。
- 每条综合建议必须带有输入指标依据；缺少依据的建议由客户端过滤。
- 不提供疾病诊断、处方、治疗方案或紧急医疗判断。
- 缺少年龄、身高、体重或份量数据时，不输出精确热量缺口、最大心率百分比或体重变化预测。

## 用户提示

所有综合分析页面均展示：健康建议仅用于生活方式参考，不替代医生诊断、治疗或紧急医疗建议。出现身体不适时，应停止相关活动并寻求专业帮助。
# 隐私与 AI 边界补充

- 恢复打卡仅使用睡眠、疲劳、酸痛和精力的 1 至 5 分评分；用户备注不发送给 AI。
- 每日计划仅发送去标识化的统计上下文与证据白名单，不发送图片路径、地点或原始记录备注。
- AI 只能生成最多三条生活方式行动，所有依据必须来自本地计算的白名单；疾病诊断、处方、治疗和药物建议均会被拦截。
- 行动完成、跳过与难度反馈保存在本地，并仅用于后续本地上下文计算。
