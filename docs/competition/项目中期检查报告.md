# 食动智衡项目中期检查报告

> 更新日期：2026 年 7 月 25 日  
> 项目名称：食动智衡  
> 项目定位：运动、饮食与恢复一体化的个人健康 Agent

## 一、项目目标

食动智衡面向有饮食管理、运动记录和健康改善需求的普通用户，解决用户需要在多个应用间切换记录、难以理解饮食与运动关联、健康建议缺少依据的问题。

项目以“记录 - 理解 - 行动 - 反馈”为主线：用户通过餐食照片、手动输入或运动 App 截图低成本记录健康行为；本地程序汇总饮食、运动、恢复与目标信息；AI 仅在可验证指标和证据白名单约束下生成行动建议；用户可执行、完成、跳过或标记“太难”，形成可调整的闭环。

## 四、阶段性成果与创新点

项目的核心不在于并列增加运动页面，而在于将饮食、运动、恢复和用户反馈组织为个人健康 Agent 的行动闭环。与普通健康问答相比，关键指标先由本地程序确定性计算，AI 只负责在证据白名单内排序和解释下一步行动；与常见饮食推荐产品相比，地点、价格、评分和联网推荐已退居次级工具路径。

创新点包括：多模态低成本记录且 AI 不直接写入真实数据；跨域关联运动负荷、运动后饮食和恢复状态；数据指纹避免陈旧结论伪装为当前计划；本地降级行动保证 AI 或网络不可用时记录与指导不中断；用户反馈可影响后续计划刷新。

## 五、现存问题

1. 健康场景“吃什么”已增加入口和本地组合建议服务，但尚未将完整 `HealthContext` 从今日 Agent 工作台传递至决策页，场景化程度仍需加强。
2. 近七天行动历史页已完成，但演示 fixture 尚未补充恢复记录和行动历史，比赛演示仍需准备稳定的脱敏数据。
3. 自动化测试以新增逻辑和首页定向测试为主，尚未完成数据库真实升级、服务端每日计划端点、完整反馈状态机与全量回归测试。
4. 尚未完成真机回归、APK 构建和断网场景演示验证；Flutter/Dart 在 Codex 沙盒用户下无法稳定访问 SDK，需使用本机用户权限执行定向命令。
5. 当前数据主要来自手动输入和截图识别，尚未接入 Health Connect、Apple Health 或穿戴设备。
