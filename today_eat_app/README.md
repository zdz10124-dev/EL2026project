# 食动智衡

食动智衡是一款运动、饮食与恢复一体化的个人健康 Agent。它通过多模态记录、确定性健康上下文、带依据的每日行动和用户反馈，形成“感知 -> 决策 -> 行动 -> 调整”的持续闭环。

A new Flutter project.
