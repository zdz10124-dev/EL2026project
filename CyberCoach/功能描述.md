## 1. 运动数据记录

### 1.1 记录方式
支持两种记录方式：
+ 用户手动输入
+ 上传运动记录截图（OCR 识别后生成草稿，用户确认后保存）

### 1.2 支持运动类型
当前版本支持两种运动：
+ 跑步
+ 游泳

### 1.3 字段定义
通用字段（跑步和游泳都适用）：
+ 记录时间（datetime）
+ 运动时长（分钟，范围 1-600）
+ 运动距离（统一存储为米）
+ 平均心率（bpm，范围 30-230）
+ 峰值心率（bpm，范围 30-230）
+ 主观疲劳评分（1-10，可选）
+ 备注（可选）

跑步扩展字段：
+ 平均配速（每公里用时）
+ 平均步频（spm）
+ 平均步幅（cm）

游泳扩展字段：
+ 泳姿（自由泳/蛙泳/仰泳/蝶泳/混合）
+ 趟数
+ 平均配速（每 100 米用时）

### 1.4 数据校验规则
+ 距离和时长不能为 0。
+ 峰值心率不能低于平均心率。
+ OCR 识别出的关键字段必须进入确认页，用户确认后才允许入库。

## 2. 运动记录分析与运动建议

### 2.1 分析流程
+ 将本次记录与个人历史记录组合后上传云端分析。
+ 分析结果以结构化格式返回，避免仅返回自由文本导致结果不稳定。

### 2.2 报告输出结构
每次运动报告必须包含：
+ 运动强度等级：低/中/高
+ 运动强度依据：基于心率区间、配速变化、时长完成度
+ 恢复建议：建议休息时长、拉伸建议、补水建议
+ 下一次运动建议：推荐项目、建议时长、建议强度
+ 激励反馈：1-2 句鼓励语，风格积极但不过度夸张

### 2.3 风险提示
+ 若检测到连续高强度或恢复不足，需在报告中加入风险提示。
+ 所有建议需附带非医疗免责声明，明确仅作运动参考。

## 3. 其他功能

### 3.1 生成运动周报（待实现）
最小可用要求：
+ 统计最近 7 天的运动次数、总时长、总距离
+ 展示平均心率与强度分布
+ 给出 2-3 条下周改进建议

验收标准：
+ 用户可在周一查看自动生成的上周报告
+ 报告生成失败时可手动重试

### 3.2 制定训练计划（待实现）
最小可用要求：
+ 用户设置目标（减脂/体能提升/习惯养成）
+ 用户设置每周可训练天数和单次时长
+ 系统生成 7 天训练安排（含休息日）

验收标准：
+ 用户首次设置后 10 秒内拿到计划
+ 用户可一键重生成计划

### 3.3 运动计划提醒（待实现）
最小可用要求：
+ 支持训练前提醒
+ 支持未完成训练的补练提醒

验收标准：
+ 用户可开关提醒
+ 用户可配置提醒时间
