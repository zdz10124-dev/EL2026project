# 关于如何应用智能体
## 困难
经过网上检索以及阅读相关文档，已知信息如下。
- 扣子无法实现在用户端本地登录南大系统，原因是扣子是公网api，无法访问用户本地。如果强行要做，需要在网上部署服务器，利用服务器进行登录。然而，这代表着需要维护服务器的费用，并且以后该软件可能无法持续发展（毕竟服务器要花钱）
- 如果使用flutter制作手机软件则可以实现本地登录并爬取信息，但是题干要求必须使用扣子开发。
## 解决方案
- 经过审题 原文“需使用火山引擎 扣子作为智能体开发工具” 可以看到，仅是规定了智能体的开发工具，没有要求是整个软件的开发工具
- 因此解决方案如下：主体用flutter做手机软件，手机本地爬取信息，保证基础功能。但是调用coze的api，通过智能体来解决进阶功能
- 怎么显得智能体这个环节不是生加上去的并且体现创新性？
1. 实现复杂信息整合：比如课程表中某些可能要求加课程群，但是里面信息是老师自己写的，无法结构化读取。此时智能体即可轻松整合此类信息并提醒用户
2. 辅助学生做计划：智能体获取学生成绩、课表等信息后，可以实现帮助学生规划学习时间，给出可用的学习计划
3. 辅助课程推荐：给智能体整上调用bilibili搜索的插件，就可以实现根据学生薄弱科目推荐对应b站课程
4. 辅助理解软件说明： 直接放一个软件说明书给用户难免过于枯燥，若利用教程引导则用户之后遗忘后难以再次查看，因此可以把软件详尽使用说明告知智能体，用户可以直接询问智能体获取软件如何使用的信息。
