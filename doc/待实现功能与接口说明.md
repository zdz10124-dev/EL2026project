# 待实现功能与接口说明

## 一、当前版本状态说明

当前版本（v1.0.0）已完成**前端 UI 框架和本地模拟逻辑**的搭建，但**所有涉及后端数据交互的功能均为模拟实现**，尚未对接真实数据源。具体来说：

- **登录功能**：当前为模拟登录，仅校验学号和密码非空，1秒后直接返回登录成功，未对接南大信息库。
- **课程数据**：使用内置的示例数据（5门课程），未从真实教务系统获取。
- **毕业进度数据**：使用内置的示例数据，未从真实教务系统获取。
- **所有数据**：仅存储在本地 SharedPreferences 中，未与任何后端服务器同步。

### 2.1 南大信息库登录认证（核心功能）

**当前状态**：`AuthProvider.login()` 中为模拟实现（`TODO: 对接南大信息库进行实际登录验证`）

**需要实现**：
- 对接南京大学统一身份认证系统（或教务系统接口）
- 实现真实的学号/密码验证

- 处理登录失败的各种情况（密码错误、账号锁定、网络超时等）
- 实现 Token 自动刷新机制

**需要提供的接口**：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/auth/login` | POST | 学号密码登录，返回 Token 和用户基本信息 |
| `/api/auth/refresh` | POST | 刷新 Token |
| `/api/auth/logout` | POST | 退出登录，使 Token 失效 |

**请求示例（登录）**：
```json

}
```

## 三、技术对接建议

### 3.1 南大信息库对接方案

对接南大信息库需要以下步骤：

1. **联系校方**：向南京大学信息化建设管理服务中心申请 API 接口权限
2. **了解认证方式**：确认使用 OAuth2.0、CAS 统一认证还是自定义 Token 认证
3. **获取接口文档**：获取教务系统开放 API 的详细文档
4. **开发测试**：在测试环境中完成接口对接和调试

### 3.2 数据加密方案

- **传输加密**：所有 API 请求使用 HTTPS 协议
- **密码加密**：使用 SHA-256 加盐哈希后传输（`EncryptionService` 已实现）
- **本地存储加密**：Token 等敏感数据使用 FlutterSecureStorage（已集成）
- **可选**：对学号、姓名等个人信息使用 AES 加密后存储（`EncryptionService` 已实现）

### 3.3 网络请求框架

当前已集成 `Dio` 网络库，并配置了：
- 自动 Token 注入（从 FlutterSecureStorage 读取）
- 统一错误处理
- 请求/响应日志打印

对接真实 API 时，只需在 `NetworkService` 中修改 `baseUrl`，并在 `AuthProvider.login()` 中替换模拟逻辑为真实网络请求即可。
